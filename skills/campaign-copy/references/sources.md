# Reference sources for campaign-copy/

- `knowledge/company/linkedin-messaging-foundation.md` — **start here for
  LinkedIn.** Not source material to draw inspiration from — the actual,
  live, currently-running sequences (pulled via API, not drafted). Any new
  LinkedIn sequence should reskin this pattern for its product line, not
  independently reinvent one — see the reconciliation note this caused in
  `outbound-motions/anz-work-management/copy/README.md`.
- `knowledge/company/sales-process-sop.md` — SPIN discovery guide: the
  three cold-open reframes ("work-scattered-across-ten-tools", "fixed the
  process before they bought the tool", "same decision fifty times a
  week") and the Problem/Implication question bank are strong raw material
  for cold email hooks and subject lines.
- `knowledge/company/sales-process-sop.md` — Objection quick-turns table
  ("we can build this ourselves", "too expensive", "not the right time")
  — useful for follow-up / breakup sequence steps.
- `knowledge/company/vision.md` — positioning language ("process before
  platform"), and credibility markers (Platinum Partner, Rising Star 2026,
  "600+ deployments") for proof points in sequences.
- `knowledge/company/sales-process-sop.md` §7 — house style rule:
  client-facing message drafts are plain text, no markdown bold/italics, no
  horizontal rules. Apply this to generated sequence copy too.
- `knowledge/company/delivery-sop.md` §6.4 — the managed-services /
  rollout-insurance offer, a possible later-sequence proof point.
