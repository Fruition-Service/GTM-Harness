## Bucket thresholds (unchanged from `skills/icp/instructions.md` §3)

- **80–100 → Tier A:** multi-persona (economic buyer / champion /
  influencer), first to launch.
- **60–79 → Tier B:** standard single-persona sequence.
- **40–59 → Tier C:** lighter-touch sequence, later batch.
- **<40 → excluded**, logged with reason.

## Orange Bucket override

If the platform/tooling signal check finds **confirmed monday.com usage**
rather than tool-sprawl pain, do not score this rubric at all — route
directly to the Orange Bucket path
(`knowledge/company/sales-process-sop.md` §5, 7-question script) via
`skills/list-segmentation/` §1. An existing monday.com account scored
through the cold rubric will produce a misleading number either way.

## Construction-vertical note

Construction leads get a slight practical edge in champion accessibility
in practice — project-based orgs tend to have a clearly titled PMO/Ops
function — but this is a working assumption to validate, not a rule to
hard-code into the scoring weights above.
